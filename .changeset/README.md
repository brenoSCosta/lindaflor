# Changesets

This folder is used by [Changesets](https://github.com/changesets/changesets) for versioning and changelog generation in this monorepo.

The changelog is generated by a custom script (`changelog.js`) that enriches each release entry with links to the related GitHub PR, commit, and author.

## Optional metadata in changeset summary

You can add optional lines at the top of a changeset summary to override automatic detection:

- `pr: #123` or `pull: 123` – link to a specific pull request
- `commit: <full-sha>` – link to a specific commit
- `author: @username` or `user: @username` – credit a specific user

Example:

```markdown
Fix login redirect loop

pr: #42
author: @yourname

Details about the fix...
```

For more, see the [Changesets documentation](https://github.com/changesets/changesets/blob/main/docs/common-questions.md).
